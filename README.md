# 산야초 길잡이 🌿

데이터가 안 터지는 산속에서도 쓰는 **오프라인 식물·버섯 확인 앱** (안드로이드).
카메라로 찍으면 폰 안의 AI가 이름 후보를 알려주고, 미리 정리해 둔 도감에서
먹을 수 있는지, 닮은 독초와 구별하는 법, 손질법·레시피, 생존 활용법을 보여줍니다.

> ⚠️ 이 앱은 "먹어도 된다"는 보증이 아닙니다. AI는 틀릴 수 있고, 버섯은 항상 "먹지 마세요"로 표시합니다.
> 확실하지 않으면 먹지 마세요. 평소에는 산주 허락 없이 임산물을 채취하면 불법입니다.

## 구성
| 폴더 | 내용 |
|---|---|
| `training/` | AI 학습 공장. iNaturalist의 CC 라이선스 사진을 모아 BioCLIP 특징으로 분류기를 학습하고, 독초를 식용으로 잘못 볼 확률을 재서 폰용 ONNX 모델로 만듭니다. |
| `.github/workflows/train.yml` | `training/`이 바뀌면 GitHub Actions에서 자동 학습 → Releases에 `plant.onnx`, `labels.json`, `report.md`, 참고 사진을 올립니다. |
| `app/` | 앱 화면(웹 기술, 완전 오프라인)과 안드로이드 껍데기, 도감 데이터 원본. |

## 데이터 출처
- 학습 사진·참고 사진: [iNaturalist](https://www.inaturalist.org) 연구 등급 관찰의 CC 라이선스 사진 (참고 사진마다 저작자 표시)
- 기반 AI: [BioCLIP](https://huggingface.co/imageomics/bioclip) (MIT)
- 독초 구별법·손질 주의: 식품의약품안전처, 산림청 국립수목원, 농촌진흥청 공개 자료

## 앱 서명 키
`app/android/signing/`의 키는 이 개인용 앱을 업데이트할 때 같은 서명을 유지하려고 넣어 둔 것입니다.
이 저장소의 Releases나 대화에서 직접 받은 APK만 설치하세요.
